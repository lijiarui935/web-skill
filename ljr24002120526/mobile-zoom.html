双指缩放、双指旋转请用手机打开；电脑可在 DevTools 设备模式下用触控模拟。

1.0x scale 1.00 · tx 0 · ty 0
怎么保证「缩放不跳」：
  1. 缩放前记下两指中点相对容器中心的位置 p、当前倍率 s1；缩放后倍率 s2。
  2. 用 tx2 = p - (p - tx1) × (s2 / s1) 修正位移，使中点在手下的那一点保持不动。
  3. 两指距离的「上一帧」在 touchstart 归零，避免拿上一轮残留距离比较导致第一帧突跳。
  4. 缩放、拖动过程中关掉 transition，松手时才加回，否则动画会和手指打架。

双指旋转（加分项）：

  1. 用 Math.atan2(dy, dx) 求两指连线的夹角，得到当前角度。
  2. 旋转角 = 本轮起始角 + 归一后的夹角差；差值归一到 ±180°，跨过 180° 时不会突然转一大圈。
  3. 不逐帧累加角度（会累积误差），每帧都用「起始角 + 总差值」重算，松手再开始新一轮。
  4. 旋转与缩放共用同一轮手势：transform: translate() scale() rotate() 顺序固定，互不干扰。
