# xiaohongshu-note-writer

> 小红书图文笔记生成助手 —— 一个可复用的自定义 Skill 示例（用于「自定义 Skill · GitHub 上传与 Pages 发布」课堂作业）。

## 名称

`xiaohongshu-note-writer`

## 描述

根据给定主题与卖点，自动产出一篇可直接发布的小红书图文笔记：包含标题、正文、话题标签和配图建议。适用于个人 IP、产品种草、生活记录等内容场景。

## 使用方式

1. 把要发布的**主题 / 产品 / 卖点**告诉本 Skill。
2. 按需补充：目标人群、平台调性（种草 / 干货 / 日常）、是否带配图。
3. 获得输出：

   - **标题**：2–3 个候选，带 emoji，突出钩子。
   - **正文**：分点 + 口语化，控制在 800 字以内，段落留白。
   - **话题标签**：8–12 个相关 `#话题`。
   - **配图建议**：封面 + 内页的构图与文案提示。

## 输出示例（节选）

```
【标题】大连陪拍初体验 📸 随手拍出韩系水光肌
【正文】
- 周六去东港海边拍了一组陪拍，出片率超高~
- 光线最好的时间是下午 4 点后，逆光拍发丝发光真的绝
- 设备：佳能 700D + 手机直出，后期一键磨皮不夸张
...
【标签】#大连陪拍 #摄影 #小红书运营
【配图】封面：人像半身 + 大字标题；内页：2–3 张成片对比
```

## 注意

- 内容需真实可信，不虚构产品效果；涉及功效类表述按平台规范处理。
- 配图建议仅作方向参考，具体成片需自行拍摄或修图。
